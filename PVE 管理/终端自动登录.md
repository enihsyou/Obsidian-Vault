本来想实现打开 WebUI 中的 shell / VNC 自动登入的，似乎自动登入是默认行为？

不需要下面的动作了，这个是给连接了显示器的真正“终端”使用的
https://superuser.com/a/1423805/2170973

```
# systemctl edit getty@.service --drop-in=autologin
# cat /etc/systemd/system/getty@.service.d/override.conf  
[Service]  
ExecStart=  
ExecStart=-/sbin/agetty --login-options '-p -- \\u' --noclear --autologin root %I $TERM
```
