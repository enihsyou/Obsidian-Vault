## 在 Docker Compose 中写多行文本

之前列举过 [[2025-10-09#在 Taskfile 中写多行文本]]，在 Docker Compose 中也有写 heredoc 的需要

```yaml
services:
  main:
    image: alpine
    entrypoint:
      - /bin/sh
      - "-c"
      - |
        echo hello
        echo goodbye
```

而在 Dockerfile 中呢，是这样 [Introduction to heredocs in Dockerfiles | Docker](https://www.docker.com/blog/introduction-to-heredocs-in-dockerfiles/)

```docker
RUN <<EOF
apt-get update
apt-get upgrade -y
apt-get install -y ...
EOF
```

## 向 Docker Compose 服务传递主机上 certbot 管理的证书

使用 Init Container 预先使用主机上的证书和私钥填充 volume，传递给以非特权身份运行的服务容器，解决有的服务在容器中自行 useradd，以非 root 身份运行应用进程，无法读取到私钥的问题。

```yaml
services:
  main:
    image: openlistteam/openlist:latest
    volumes:
      - app-certs:/certs:ro
    depends_on:
      cert:
        condition: service_completed_successfully

  cert:
    image: alpine
    volumes:
      - /etc/letsencrypt/live/list.home.kokomi.site:/etc/letsencrypt/live/list.home.kokomi.site:ro
      - /etc/letsencrypt/archive/list.home.kokomi.site:/etc/letsencrypt/archive/list.home.kokomi.site:ro
      - app-certs:/certs
    entrypoint:
      - /bin/sh
      - -c
      - |
        cp -L /etc/letsencrypt/live/list.home.kokomi.site/fullchain.pem /certs/fullchain.pem
        cp -L /etc/letsencrypt/live/list.home.kokomi.site/privkey.pem /certs/privkey.pem
        chown 1001:1001 /certs/*.pem
        chmod 600 /certs/*.pem

volumes:
  app-certs:
```

## 通达信在分时图中取昨日最高价

#股票软件
首先需要用通达信的“盘后数据下载”把数据补充完整，然后使用两个公式：

```zig
前一收盘价:REF(CLOSE, 1);
```

```zig
昨收盘价:分时价格.前一收盘价#DAY;
```

- [在分时图上显示前一天的最高价和最低价_金芽趋势好用的复盘网站选股通达信股票入门趋势交易推广者](https://ijinrong.net/School/20)

不建议使用这些文章提出的方式，因为它们需要 <kbd>Alt + 3</kbd>多显示几天分时图才能计算，而且 `BARSLAST` 函数在处理多日分时图存在 off by one 问题。

```zig
REF(CLOSE,SUMBARS(DAY<>REF(DAY,1),1));
REF(CLOSE,BARSLAST(DAY<>REF(DAY,1))+1);
```
