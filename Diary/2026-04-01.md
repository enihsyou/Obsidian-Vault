## Win+C 不能唤醒 Microsoft Copilot

刚想在 Microsoft Store 更新一下 Microsoft Copilot 应用，到 146.0.3856.80，更新完进去把语言改成简体中文后，发现应用打不开了。

卸载重装可以打开，这次提示 "这不是你的错，而是我的问题 出错了。我可能只是需要时间来刷新。"，估计和定位有关，总之就是不可用。

Microsoft Copilot 应用在 [美国市场](https://apps.microsoft.com/detail/xp9cxngppj97xx?hl=en-US&gl=US) 可用，而在 [中国市场](https://apps.microsoft.com/detail/xp9cxngppj97xx?hl=zh-CN&gl=CN) 则不提供。开全局重装，只在第一次可启动，然后又回到开头的打开网页现象。
且 <kbd>Win+C</kbd> 快捷键和任务栏图标快捷键都废了，不会弹出窗口，而是打开 Edge 浏览器。当然 `Windows 设置 > 蓝牙和其他设备 > 键盘 > 在键盘上自定义 Copilot 键` 我是设置过的。
只要 Copilot 没有运行在前台，它就打开浏览器。

因为它们都是触发 `microsoft-edge://?ux=copilot&tcp=1&source=hotkey` 这段启动指令，或者 `ms-copilot://`，而系统识别到 Copilot 被禁用了，就打开浏览器了。

- [WindowsCopilot/Enable-WindowsCopilot.ps1 in main · rberghuis/WindowsCopilot](https://github.com/rberghuis/WindowsCopilot/blob/main/Enable-WindowsCopilot.ps1)
- [windows 11 - Disabled copilot on Win11 23H2 and now I can't get it back - Super User](https://superuser.com/questions/1861745/disabled-copilot-on-win11-23h2-and-now-i-cant-get-it-back)

之后尝试删除 `$HOME/AppData/Local/Microsoft/Copilot` 能启动一次。

`2026-04-06` 原来是微软在犯蠢 [微软推送 Win11 新版 Copilot：弃用原生框架内置完整 Edge，内存占用飙升至 1 GB](https://t.me/zaihuapd/40699)，反正我全换成 Pake 版了：[[#桌面端使用 AI Chat 的姿势]]
`2026-04-13` 突然发现系统重启后， Edge 自动更新到 146.0.3856.109 版本又能在右上角和侧边栏显示 Copilot 按钮了

## 桌面端使用 AI Chat 的姿势

看来使用桌面端应用不太行了，也好，本来它们就是一个 Chromium 浏览器。

再次尝试新的路子，比如浏览器边栏插件 [creosB/AI-Side-Panel-Extension](https://github.com/creosB/AI-Side-Panel-Extension)。
然后发现它受到 iframe 嵌入安全限制，无法打开 Microsoft Copilot。并且没有页面缓存，切换 AI 会刷新页面。

倒是 Edge 目前还保留了侧边栏功能，虽然变得极其难用了以及我怎么也找不到**侧边栏按钮**（更别提原本在右上角的那个 Copilot 按钮，现在就是个空的占位符在那里）。但还是能把当前打开的页面固定在侧边栏的。

然而侧边栏会占用浏览器窗口空间，而且不能单独悬浮出来。将站点以应用形式安装成了目前的选择。它能共享浏览器进程，固定到开始屏幕和任务栏。但 [[需求应对软件#^8b5e0e |AltTaber]] 会把浏览器窗口合并在一起，相比单独的桌面应用体验差了点。

那么就搞独立应用呗，`pake-cli` 刚好就能从网页创建应用。安装完重新登录下。缺点就是不能继承浏览器的插件，页面快捷键也受限。

```shell
wget -O "https://copilot.microsoft.com/static/cmc/favicon.svg"
magick -background none favicon.svg -define icon:auto-resize=256,128,64,48,32,16 favicon.ico
pake https://copilot.microsoft.com/ --name "Microsoft Copilot" --icon ./favicon.ico
```

## Bun install global 后 ~/.bun/bin 不生成可执行文件

我在使用 `bun install --global` 安装 CLI 工具时，无法找到可执行文件。
