## ChatGPT 桌面端应用保持官方登录态同时使用第三方 LLM 端点

昨天部署了 [CLI Proxy API](https://github.com/router-for-me/CLIProxyAPI)，把手头上的 LLM 提供商都放了进去，这样就可以在同一个地方管理、监控手头上所有设备、所有工具使用 LLM 的情况了。但当设置到 ChatGPT / Codex 应用的时候，每次打开应用的时候它都需要我重新进行 onboarding 的流程。即便我采用了这个设置。

```toml
model_provider = "cli-proxy-api"

[model_providers.cli-proxy-api]
name = "CLI Proxy API"
base_url = "https://cli-proxy-api.home.kokomi.site/v1"
wire_api = "responses"
supports_websockets = true
requires_openai_auth = true
```

这个在以前见过，我记得 cc-switch 已经修过了，它的核心是保留原有的 `auth.json` 文件不动，它里面继续存着官方的认证信息。但是使用 `experimental_bearer_token` 属性来使用自定义的 token，来走第三方的 model provider。

```toml
[model_providers.cli-proxy-api]
# ...
experimental_bearer_token = "..."
```

这么设置之后，发布的会话在 ChatGPT App 中就会被认为使用的是 ChatGPT 官方的认证，不会提示 `模型提供商不匹配`。
