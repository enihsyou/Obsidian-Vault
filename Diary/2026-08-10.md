## Grafana Provisioning 中设置提交作者和主题

设置好 Provisioning 后，默认提交作者和提交内容都一言难尽，还会固定添加 `Grafana-saved-by`

虽然 WebUI 中输入框只支持单行的，不过可以绕过 UI：Grafana 13.1 的 Git Sync Repository 本身是 CRD，官方支持用 `gcx resources edit repository/<REPOSITORY_NAME>` 修改 Repository 配置：

```json
  "spec": {
    "commit": {
      "signerEmail": "314952158+kokomi-grafana[bot]@users.noreply.github.com",
      "signerName": "Kokomi Grafana",
      "signerIsAuthor": true,
      "singleResourceMessageTemplate": "{{action}} {{resourceKind}}: {{title}}\n\nGrafana-saved-by: {{userName}} ({{userLogin}})\nCo-Authored-By: {{userName}} \u003c{{userEmail}}\u003e"
    },
  },
```

- 在 [`appendSavedByTrailer()`](https://github.com/grafana/grafana/blob/v13.1.0/public/app/features/provisioning/utils/commitMessage.ts#L120) 有个判断，如果模板里自己已经写了 `Grafana-saved-by: ...` Grafana 就不会再追加一次。
- Email 的构成见 [[Diary/2026-06-11#使用 GitHub App 以 Bot 身份创建属于 AI Agent 的提交]]
- 目前 v13.1.0 Author 还不好改 [Git Sync: Commit author remains noreply@grafana.com when custom signer identity is configured · Issue #129908 · grafana/grafana](https://github.com/grafana/grafana/issues/129908)，目前固定为 `Grafana <noreply@grafana.com>`，倒是有个还未上线的 [Provisioning: Attribute Git Sync commits to the acting user by amalavet · Pull Request #127983 · grafana/grafana](https://github.com/grafana/grafana/pull/127983) 功能可以试试
