## 从 Edge 导入到 Vivaldi
Vivaldi 浏览器体验上满足了几个痛点，十分想切换
- 堆栈标签页，可以覆盖 [[Tree Style Tab]] 的功能

说到缺点
1. 导入数据不完整，因为我设置了[[MSEdge 磁盘写入]] 路径，它只识别到旧版留下的那些数据（只有3月更改用户文件夹路径之前的部分），即便手动选择用户目录也是一样，直到我软链了一份现在的版本到原位置

3. 标签栏的文字就是有些糊
4. 两级式标签栈切换过去会突然改变整体宽度，这种时候用折叠式反而更好

## 给 Docker Daemon 启用 TLS 验证
```shellsession title="On Server Side"
mkdir .docker
step ca certificate docker.home.kokomi.site .docker/key.pem .docker/cert.pem

cat > /etc/docker/daemon.json <<< EOF
{
  "hosts": ["unix:///var/run/docker.sock", "tcp://0.0.0.0:2376"],
  "tls": true,
  "tlscert": "/root/.docker/cert.pem",
  "tlskey": "/root/.docker/key.pem",
  "tlsverify": false
}
EOF

rc-service docker restart
```

```shellsession title="On Client Side"
docker context update kokomi --description "Homelab docker host" --docker "host=tcp://docker.home.kokomi.site:2376,ca=C:\Users\enihsyou\.docker\ca.pem"
```
