## 遵从 PEP 514 让 UV 识别 vfox 安装的 Python

很早之前就想到 version fox / pyenv / uv / PythonCore 等工具安装的 Python 都在不同地方，而 Windows 自带的 `~/AppData/Local/Microsoft/WindowsApps/python.exe` 居然能识别 PythonCore 和 UV 安装的。后来知道它们是符合了 [PEP 514](https://peps.python.org/pep-0514/) 规范

那就想给 vfox 安装的也加入到 PEP 514 中，以前手动加过，现在完全可以让 Agent 来。

```reg
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Python\vfox\v-3.14.3\InstallPath]
@="C:\\Users\\enihsyou\\.vfox\\cache\\python\\v-3.14.3\\python-3.14.3"
"ExecutablePath"="C:\\Users\\enihsyou\\.vfox\\cache\\python\\v-3.14.3\\python-3.14.3\\python.exe"
"WindowedExecutablePath"="C:\\Users\\enihsyou\\.vfox\\cache\\python\\v-3.14.3\\python-3.14.3\\pythonw.exe"
```
