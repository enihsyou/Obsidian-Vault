## 自动暗色模式的 SVG 图片

### Embedded CSS Query

- [Making single color SVG icons work in dark mode | hidde.blog](https://hidde.blog/making-single-color-svg-icons-work-in-dark-mode/)
好处是一个文件解决问题，不用下两个文件。

```xml
<svg width="131" height="42" viewBox="0 0 131 42" fill="none" xmlns="http://www.w3.org/2000/svg">
<style>
:root{
    /* default: light theme */
    --bg: white;
    --fg: black;
}
@media (prefers-color-scheme: dark){
:root{
	--bg: black;
	--fg: white;
}
}
</style>
<path fill="var(--bg)" stroke="var(--stroke)"/>
<path fill="var(--fg)"/>
</svg>
```

### Responsive Image

- [Guide to HTML dark mode responsive images | kyoshee](https://kyoshee.com/articles/guide-to-html-dark-mode-responsive-images)
- [Dark Mode Support in WebKit | WebKit](https://webkit.org/blog/8840/dark-mode-support-in-webkit/)

```html
<picture>
    <source srcset="mojave-night.jpg" media="(prefers-color-scheme: dark)">
    <img src="mojave-day.jpg">
</picture>
```

但如果想要动态指定切换亮暗色模式，似乎得用点 CSS

```css
/* hide content for system theme */
:root:not(.light-theme):not(.dark-theme) {
    [data-light-theme],
    [data-dark-theme] { display: none; }
}

/* hide content for light theme */
:root.light-theme {
    [data-system-theme],
    [data-dark-theme] { display: none; }
}

/* hide content for dark theme */
:root.dark-theme {
    [data-system-theme],
    [data-light-theme] { display: none; }
}
```
