## Zed 插件在 Windows 平台上的问题

这个问题结合了多个 Issue，一些提了 PR

- zed-code-stats 在 Windows 平台因为下载到 Zip 包无法解压 [Failed to iterate over archive on Windows · Issue #3 · maxdeviant/zed-code-stats](https://github.com/maxdeviant/zed-code-stats/issues/3)
- zed-wakatime 在 Windows 平台因为 file URI 未处理盘符导致不识别项目名 [Wakatime doesn't record project name · Issue #80 · wakatime/zed-wakatime](https://github.com/wakatime/zed-wakatime/issues/80)
- zed-powershell 在 Windows [Remove redundant slash at the start of the path on Windows by vkibalyuk · Pull Request #18 · wingyplus/zed-powershell](https://github.com/wingyplus/zed-powershell/pull/18)
- Zed 插件 API 不支持使用 GITHUB_TOKEN ，启动时检查更新的插件因为 GitHub 限流而失败 [Support http_client injecting GITHUB_TOKEN (fix for GitHub 403 response: API rate limit exceeded errors) · 议题 #9483 · zed-industries/zed](https://github.com/zed-industries/zed/issues/9483)
