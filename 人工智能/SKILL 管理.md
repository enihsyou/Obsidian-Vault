目前似乎没有很好的统一管理方式，都各自 Vibe 一套管理工具

我现在用 [AI CLI Skills Sync Tool | skillshare](https://skillshare.runkids.cc/) 挺好的，比 vercel-labs/agent-skills 要好，也比内嵌在 cc-swticher 等各个工具中的管理工具好。
重点是 single of truth，版本管理，随意启停。

不过目前的 v0.20.18 版本，同步来自 GitHub 需要在命令行运行，如 `skillshare install tavily-ai/skills`，在 WebUI 上不会被统计为 GitHub 源
