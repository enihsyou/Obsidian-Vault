## 重置 Git 提交的作者信息
历史提交用了错误的用户名和邮件（比如受组织要求），想要修改成正确的。并且尽量保持信息不变。
- [git - How do I change the author and committer name/email for multiple commits? - Stack Overflow](https://stackoverflow.com/questions/750172/how-do-i-change-the-author-and-committer-name-email-for-multiple-commits)
- [How to update git commit author, but keep original date when amending? - Stack Overflow](https://stackoverflow.com/questions/41301627/how-to-update-git-commit-author-but-keep-original-date-when-amending)
```shell
# 添加参数来修改为正确的用户信息
git config user.name
git config user.email 
# 修改最后一个提交的用户信息，但是会重置提交时间
git commit --amend --reset-author
```
