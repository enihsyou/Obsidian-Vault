## 创建功能完整的反弹 Shell

也就是带 TTY，能正常运行 vim，passwd 等

- [Upgrading reverse shells | Jonathan Hodgson's Blog](https://jonathanh.co.uk/blog/upgrading-reverse-shells/)
- [Hacking: Getting a functional TTY from a reverse shell. — Steemit](https://steemit.com/hacking/@synapse/hacking-getting-a-functional-tty-from-a-reverse-shell)

在监听端用 nc 开启监听，并留一手在退出后恢复 echo 回显

> 为了绕过 [[2025-09-08#Windows SSH 粘贴文字会丢失开头的一些字符]] 的问题，在 nc 之前就计算好 stty 的参数

```shell title="Listener Side"
cols=$(stty -a < /dev/tty | grep -oE 'columns [0-9]+' | cut -d' ' -f2)
rows=$(stty -a < /dev/tty | grep -oE 'rows [0-9]+' | cut -d' ' -f2)
echo "Copy these to clipboard and paste back to this session:"
echo "stty rows $rows cols $cols"
echo "export TERM=xterm-256color"

(echo 'echo 1'; cat ) | nc -nvlp 3333 & wait $!; stty -raw echo
```

在取得反弹 Shell 的被控端，用两种方式之一启动带 TTY 的子进程，再按 <kbd>Ctrl + Z</kdb> 置于后台

```shell title="Inside Reverse Shell"
script /dev/null
python3 -c 'import pty; pty.spawn("/bin/bash")'
<Ctrl+Z>
```

回到监听端的 Shell 后，把 `stty` 那些行贴入 reverse shell

```shell title="Listner Side"
stty raw -echo < /dev/tty; fg
<paste><enter>
```

实践之后可以省略简单些

```shell
socat FILE:`tty`,raw,echo=0 TCP-LISTEN:3333,reuseaddr,fork
```
