## 向登录用户展现动态内容
也就是展现 banner / motd，只不过 banner 一般是静态的，motd 是动态的。

Banner 可以通过 sshd_config 的 Banner 参数配置，在登录时展示对应文件的内容，但对 SFTP 也有影响。[linux - SSH MOTD per user - Server Fault](https://serverfault.com/questions/653399/ssh-motd-per-user)

目前在 Debain 上，motd 由 [motd - Debian Wiki](https://wiki.debian.org/motd) pam_motd 创建，执行 `/etc/update-motd.d` 下的脚本生成动态内容
动态的 motd 不适合放与当前用户有关的实时信息

```shell
cp /etc/update-motd.d/20-fastfetch /etc/profile.d/20-fastfetch.sh

# cat /etc/profile.d/20-fastfetch.sh  
#!/usr/bin/env bash  
printf "\n"  
fastfetch --pipe false
```

这里的差别还有，Last login 这行出现在上面还是下面

```
#!/usr/bin/env bash  
printf "\n"  
  
PPID1=`cat /proc/$PPID/status | grep PPid | awk '{ print $2 }'`  
PPID2=`cat /proc/$PPID1/status | grep PPid | awk '{ print $2 }'`  
luser=`ps -x | grep $PPID2 | awk '{ print $6 }' | sed "s/[[:digit:].-]//g"`  
  
# fastfetch read username from environment variable,  
# so override it that we can print logging user  
# https://github.com/fastfetch-cli/fastfetch/blob/805e2774293d27f0f5b803ff2b35f3332e2a1bb6/src/util/platform/FFPlatform_unix.c#L179  
USER="$luser" fastfetch --pipe false
```
