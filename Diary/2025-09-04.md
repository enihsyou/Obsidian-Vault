## 给 OpenRC 的服务添加环境变量

服务除了在 `/etc/init.d/<service>` 定义了服务脚本，还会 source `/etc/conf.d/<service>` 文件，在里面可以写 `export`。

不建议改 init.d 目录的文件，conf.d 就是用来改的。

说真的这 OpenRC 的说明和文档真是难找，特别是隐式读取的配置文件 😩。

## 将 PVE 主机的目录挂载到节点上

我想在 LXC 容器之间共享 home 目录，免去配置 bashrc 等的过程，挂载目录最简单。

- [two reliable ways to bind-mount a host directory into an unprivileged container : r/Proxmox](https://www.reddit.com/r/Proxmox/comments/slfhka/two_reliable_ways_to_bindmount_a_host_directory/)
- [Bind Mount Points - Proxmox VE](https://pve.proxmox.com/wiki/Linux_Container#_bind_mount_points)

```shell
# 把原始目录复制一份，用来做只读共享，注意替换软链接为真实文件
cp -R -HL /home/enihsyou /home/pct
# 修改所有权允许容器用户访问
chown 100000:100000 -R /home/pct
# 以只读方式挂载到容器中
pct set 103 -mp0 /home/pct,mp=/root,ro=1
```
