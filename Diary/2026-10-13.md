## 更新 BIOS 版本至 F12 后启动 Windows 提示 0xC0430001 错误

主板之前安装的是 2025-01-04 的 `F3j` 版本（现在居然下架了），这次想更新到 `F12`，看看有没有新功能。没想到安装完之后，不仅重置了我的 BIOS 超频设置，还直接无法启动 Windows，提示“你的电脑需要恢复”，错误码是 `0xC0430001`。

几经周折，最后查到 BIOS 从 F9 版本开始默认启用了 Secure Boot。虽然我记得之前也是开启的，但这次在 BIOS 中关闭 Secure Boot 之后，确实就能启动系统了。

启动之后，Windows Hello PIN 登录直接废了，只能用密码登录。在 Windows 账户设置里，PIN 那一栏显示“该选项不可用”，提示“抱歉，此 PIN 不能用于你组织的资源”。看上去需要一个组织账户，但我用的是个人账户。

不过，在 Windows 登录界面点重置 PIN，倒是能重新设置。到这里也算勉强弄完了。再加上以后肯定会遇到的 [[Diary/2026-09-18#KB5129195 更新导致 Primo Ramdisk 驱动签名失效]]，这个 Secure Boot 还真的得关闭。

## 调节 Windows 最大处理器状态

另外，这次 BIOS 更新之后，处理器电源管理的表现也不一样了。之前在电源设置里，把最小和最大处理器状态都调到 0%，CPU-Z 显示的倍频范围虽然是 6–55，实际频率却最多只能降到 3.5 GHz 左右，节能模式也没能真正把频率降下来。

更新之后，最大处理器状态设置有用了。把最大处理器状态设为 31%，倍频上限就只有 6 倍，约合 0.61 GHz。此时 CPU-Z 单线程 69 分、多线程 852.6 分，满载功耗比闲置时的 28 W 只增加了 1 W。不过系统也变得非常慢，基本处于不可用的状态。

把上限调到 60%，频率约为 2.31 GHz，满载功耗最高 35 W，温度 60℃（环境温度25℃），CPU-Z 单线程 268.4 分、多线程 3493.497 分。

上限调到 99%，CPU-Z 单线程 505.5 分、多线程 5969.8 分。相比 i7-7700K，单线程略强，多线程则翻了一倍，功耗只有约 50 瓦，温度也只有 60 度，非常适合当做节能模式。

不过这里不能调到 100%，一调上去就会自动超频，超过基准的 3.8 GHz，跳到 5.5 GHz 以上。

咨询 ChatGPT，它提到其实电源管理里面还有一个最大处理器频率的隐藏选项，在终端中执行，便可将当前电源方案的最大处理器频率设成 4.5GHz

```powershell
powercfg /setacvalueindex SCHEME_CURRENT SUB_PROCESSOR PROCFREQMAX 4500
powercfg /setactive SCHEME_CURRENT
```

得到这样的输出，从此以后，这项配置甚至可以在 `powercfg.cpl` 的图形界面中看到

```console
电源方案 GUID: 381b4222-f694-41f0-9685-ff5bb260df2e  (平衡)
  GUID 别名: SCHEME_BALANCED
  子组 GUID: 54533251-82be-4824-96c1-47b60b740d00  (处理器电源管理)
    GUID 别名: SUB_PROCESSOR
    电源设置 GUID: 75b0ae3f-bce0-45a7-8c89-c9611c25e100  (处理器最大频率)
      GUID 别名: PROCFREQMAX
      最小可能的设置: 0x00000000
      最大可能的设置: 0xffffffff
      可能的设置增量: 0x00000001
      可能的设置单位: MHz
    当前交流电源设置索引: 0x00001194
    当前直流电源设置索引: 0x00000000
```

此时 CPU-Z 单核心 625.4 分，多核心 6941.3 分，最大温度 63℃，最大功耗 63 瓦。

最后把三个电源模式的设置记在一起。节能模式通过最大处理器状态限制超频，目的是控制功耗，让风扇不要转；平衡模式则在性能、功耗和噪音中取得平衡：

| 电源模式 | 最小处理器状态 | 最大处理器状态 | 最大处理器频率 |
| --- | --- | --- | --- |
| 节能 | 0% | 99% | — |
| 平衡 | 0% | 100% | 4.5 GHz |
| 高性能 | 100% | 100% | 不限制 |

## AMD 9700X 超频配置

刚才更新 BIOS，把之前的配置都清空了。倒也还能接受，我本来就喜欢定期大赦天下，从默认值开始感受新版本有什么变化。不过我居然一直没记录过超频参数，这次只能从头开始试，顺便把过程和最后留下的配置记下来。

内存用了默认的 EXPO 配置，6400 MT/s，时序 32-39-39-89。`UCLK = MEMCLK` 不稳定，只能用 `UCLK = MEMCLK/2`。

CPU 一开始设的是 PPT 96 W、TDC 84 A、EDC 160 A，CPU Boost Override +100 MHz，PBO Scalar 3x，Curve Optimizer 全核心 -10，Tji 保持默认 95℃。这组配置下核心最高温度到了 80℃，PPT 已经打满，还有继续调整的空间。

之后用 Ryzen Master 做 Curve Optimizer 自动优化，给出的建议居然是全核心 -53，CPU-Z 跑分也提升了不少。改成每核心优化，建议值则是 -60，多线程分数又高了一点，不过这两次都受到了 PPT 限制。我又把 PPT 放到 105 W，Tji 限到 92℃，多线程分数还能继续往上走。几次结果放在一起比较：

| 配置                     | CPU-Z 单线程 / 多线程 | 最高温度  |
| ---------------------- | --------------- | ----- |
| PPT 96 W，全核心 -10       | 787.6 / 7753.4  | 80℃   |
| PPT 96 W，全核心 -53       | 821.8 / 8494.6  | 78.5℃ |
| PPT 96 W，每核心优化，建议值 -60 | 815.8 / 8589.8  | 78.4℃ |
| PPT 105 W，Tji 92℃      | 820.6 / 8856.1  | 92.3℃ |
| 最终配置                   | 845.8 / 9010.3  | 95.5℃ |

最后留下的是 PPT 125 W、TDC 96 A、EDC 160 A，Curve Optimizer 全核心 -50，Tji 恢复默认。相比老古董 Intel i7-7700K 的单线程 492 分、多线程 2648 分，我觉得足够了。

## 控制主板和内存条的灯光

我向来不喜欢 RGB 光污染，显示设备都是 OLED，房间里也总是不开灯、漆黑一片。偏偏手上的设备都是冲着性能买的，却一个个自带 RGB，还是得想办法关掉。

我的主板是 [GIGABYTE X870E AORUS ELITE WIFI7 (rev. 1.0)](https://www.gigabyte.cn/Motherboard/X870-AORUS-ELITE-WIFI7-ICE-rev-10-11/support)。安装 `GIGABYTE IT5711 RGB lighting controller firmware upgrade package` 之后，就可以在 Windows 的“个性化 > 动态光效”里管理灯光。

内存条是 KINGBANK 金百达白刃系列 KRRW DDR5 RGB 内存，控制灯光需要单独启动 [Kingbank RGB Control Software](https://www.kingbank.com/ControlHub.html)。CPU 散热器是海盗船 H115i，控制它的灯光还得另外安装 CORSAIR iCUE。

各个厂商自己玩自己的。今天看到 [Glance](https://github.com/lulu-loopp/glance) v.3.0 添加了通过 OpenRGB 控制设备灯光的功能，本以为终于能统一管理了。实际用起来，设备虽然能识别，~~但并不能控制我设备上的任何灯光。~~

后来才发现是我不会玩，需要重启设备。重启后能识别和控制主板（Gigabyte Fusion2 SMBus）和内存条（ENE SMBus Device），但还是识别不到 Corsair H115i 水冷散热器。它明明列在支持列表里，我估计是设备太老了。

想要关闭灯光，把颜色调成黑色就行。
