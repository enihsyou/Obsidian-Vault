## Google Antigravity 因账户地区问题无法使用

使用 Antigravity / Antigravity Tools 时提示 `Permission denied on resource project useful-core-shnwk.`

- [400错误，Invalid project resource name · 议题 #1841 · lbjlaq/Antigravity-Manager](https://github.com/lbjlaq/Antigravity-Manager/issues/1841#issuecomment-3976604209)

需要去 [policies.google.com/country-association-form](https://policies.google.com/country-association-form) 查看账户所在地区，如果处于不支持的地区，提交申请开始祈祷。

## Win+C 不能唤醒 Microsoft Copilot

刚想在 Microsoft Store 更新一下 Microsoft Copilot 应用，到 146.0.3856.80，更新完进去把语言改成简体中文后，发现应用打不开了。

卸载重装可以打开，这次提示 "这不是你的错，而是我的问题 出错了。我可能只是需要时间来刷新。"，估计和定位有关，总之就是不可用。

Microsoft Copilot 应用在 [美国市场](https://apps.microsoft.com/detail/xp9cxngppj97xx?hl=en-US&gl=US) 可用，而在 [中国市场](https://apps.microsoft.com/detail/xp9cxngppj97xx?hl=zh-CN&gl=CN) 则不提供。开全局重装，只在第一次可启动，然后又回到开头的打开网页现象。
且 <kbd>Win+C</kbd> 快捷键和任务栏图标快捷键都废了，不会弹出窗口，而是打开 Edge 浏览器。当然 `Windows 设置 > 蓝牙和其他设备 > 键盘 > 在键盘上自定义 Copilot 键` 我是设置过的。
只要 Copilot 没有运行在前台，它就打开浏览器。

因为它们都是触发 `microsoft-edge://?ux=copilot&tcp=1&source=hotkey` 这段启动指令，或者 `ms-copilot://`，而系统识别到 Copilot 被禁用了，就打开浏览器了。

- [WindowsCopilot/Enable-WindowsCopilot.ps1 在分支 main · rberghuis/WindowsCopilot](https://github.com/rberghuis/WindowsCopilot/blob/main/Enable-WindowsCopilot.ps1)
- [windows 11 - Disabled copilot on Win11 23H2 and now I can't get it back - Super User](https://superuser.com/questions/1861745/disabled-copilot-on-win11-23h2-and-now-i-cant-get-it-back)


最后还是用不了，回归网页版吧。毕竟 Gemini 也得用网页版
