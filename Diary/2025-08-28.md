## WSL2 终端无法启动

尝试打印了进程树，截出卡住的一段

```txt
/init
  /init
    -bash
      bash
        sudo ps -efH
    /bin/sh /etc/update-motd.d/50-landscape-sysinfo
      /bin/sh /etc/update-motd.d/50-landscape-sysinfo
        /usr/bin/python3 /usr/bin/landscape-sysinfo
          [who] <defunct>
```

只要运行 `sudo`，`landscape-sysinfo`（被 motd 触发）都会卡住，`Ctrl+C` 无效，甚至想要 `wsl --shutdown` 也是卡很久。重启 WSL 肯定能好，但这明显是问题。

其他人也有遇到过，

- [WSL2 process never releases and gets frozen forever when stdin is redirected](https://github.com/microsoft/WSL/issues/4424#issuecomment-531382859)

曾经我验证过和 Docker 的 Resource Save Mode 有关，但这次没有开 Docker Desktop。
