## Windows 11 夜间自动唤醒还重启

最近经常遇到，晚上设备置入睡眠，起来之后像是重启了一样。任务管理器的 `正常运行时间` 证明确实重启了。

在系统日志中包含这样的信息，

```log
系统已从低功耗状态中恢复。

睡眠时间:  ‎2025‎-‎08‎-‎30T21:08:41.487212400Z
唤醒时间: ‎2025‎-‎08‎-‎30T23:44:34.991788000Z

唤醒源: Unknown, but possibily due to timer - Windows 将执行“NT TASK\Microsoft\Windows\UpdateOrchestrator\Schedule Wake To Work”计划的任务，该任务请求唤醒计算机。
```

然后安装系统更新，自动给我重启了。

我的工作区那么多窗口的工作状态啊！我内存盘里的东西啊！🤬

```
进程 C:\WINDOWS\uus\packages\preview\AMD64\MoUsoCoreWorker.exe (ENIHSYOU-PC) 由于以下原因已代表用户 NT AUTHORITY\SYSTEM 启动计算机 ENIHSYOU-PC 的 重启: 操作系统: Service Pack (计划内)
 原因代码: 0x80020010
 关机类型: 重启
 注释: 
```

在计划任务 `\Microsoft\Windows\UpdateOrchestrator` 下确实找到了 `Schedule Wake To Work` 这个任务，触发器也匹配唤醒时间，设置里也允许 `唤醒计算机运行此任务`。它的状态是 `禁用`，原因是设置了 `只运行一次`。
直接操作还提示无权限禁用，需使用管理员权限打开计划任务 （`psexec -i -s mmc.exe taskschd.msc`），取消勾选允许唤醒。
注意光禁用还没完，每次系统更新后，又会回到开启状态；收到系统更新清单之后，又会回到开启状态，需要重复操作。简直就是傻逼，即便是 [[2025-10-10#MoUsoCoreWorker.exe 在工作时间外自动重启 Windows]] 关闭了自动更新也没用，只有点暂停更新有效。

这行这个可以找出计划任务里还有哪些允许唤醒，除了已经禁用的还有这些
- [windows - use powershell to find scheduled tasks set to wake the computer - Stack Overflow](https://stackoverflow.com/questions/20529169/use-powershell-to-find-scheduled-tasks-set-to-wake-the-computer)

```powershell
$ Get-ScheduledTask | where {$_.settings.waketorun}

TaskPath                                       TaskName                          State
--------                                       --------                          -----
\Microsoft\Windows\UpdateOrchestrator\         Schedule Wake To Work             Ready
\Microsoft\Windows\.NET Framework\             .NET Framework NGEN v4.0.30319... Disabled
\Microsoft\Windows\.NET Framework\             .NET Framework NGEN v4.0.30319... Disabled
\Microsoft\Windows\InstallService\             WakeUpAndContinueUpdates          Disabled
\Microsoft\Windows\InstallService\             WakeUpAndScanForUpdates           Disabled
\Microsoft\Windows\SharedPC\                   Account Cleanup                   Disabled
```

或许 Unknown 还有别的原因，比如 [设备管理器内的有线网卡“样式对比唤醒”](https://www.izilzty.com/?post=22)
为了避免将来再次有这麻烦，一个个手动关闭后，我再去 `powercfg.cpl` 里把所有电源计划的 `睡眠 > 允许使用唤醒定时器` 关了。

- [Computer wakes from sleep automatically every night - Microsoft Q&A](https://learn.microsoft.com/en-us/answers/questions/3212974/computer-wakes-from-sleep-automatically-every-nigh)

`2025-10-12` 最近换用有线网卡，又遇到了 Unknown 原因唤醒的问题，或许和网卡的 ["样式对比唤醒"](https://www.izilzty.com/?post=22) 设置有关
