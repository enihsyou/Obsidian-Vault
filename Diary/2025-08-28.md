## 在 PowerShell Function 中使同步地 Dot Source 作用于全局

我想实现的是一个 Lazy Loader，在首次执行的时候初始化，降低一些命令行工具对终端启动性能的影响。对应的 Bash 版本长这样

```bash
##### nvm (node version manager) #####
# placeholder nvm shell function
# On first use, it will set nvm up properly which will replace the `nvm`
# shell function with the real one
# take from web-cache of: https://peterlyons.com/problog/2018/01/zsh-lazy-loading
function nvm() {
  echo "🚨 nvm not loaded! Loading now..." >&2
  unset -f nvm
  export NVM_DIR="$HOME/.nvm"
  [ -s "$NVM_DIR/nvm.sh" ] && source "$NVM_DIR/nvm.sh"
  nvm "$@" # invoke the real nvm function now
}
```

也就是想要 `function F { . script.ps1 }` 能影响 Global Scope，一般来说 dot source 只会作用于 local 范围，也就是函数作用域，离开函数就消失了，无法给全局作用域添加函数。

之前实现的 [fsackur/ProfileAsync: Load your powershell profile asynchronously, so you can get to the prompt faster.](https://github.com/fsackur/ProfileAsync) 是异步的，不太适用这种情况。用到的 Runspace 替换技术太复杂了

实际上如 [Question about dot sourcing inside functions : r/PowerShell](https://www.reddit.com/r/PowerShell/comments/1dz56cx/question_about_dot_sourcing_inside_functions/) 所说，只需要定义个 Module，然后在函数中 `Import-Module` 即可。

```powershell title="X-CMD.psm1"
# A simple module that only do dot source.
# By Import-Module this, all functions in the module will be available in the global scope.
# https://www.reddit.com/r/PowerShell/comments/1dz56cx/question_about_dot_sourcing_inside_functions/

# https://cn.x-cmd.com/start/windows
if (Test-Path "$Home\.x-cmd.root\local\data\pwsh\_index.ps1") {
    . "$Home\.x-cmd.root\local\data\pwsh\_index.ps1"
}; # boot up x-cmd.

```

```powershell
function x {
    Write-Host "🚨 x not loaded! Loading now..."
    Remove-Item -Path "Function:x"
    Import-Module -Name "X-CMD.psm1" -Force -DisableNameChecking
    x @args
}
```

### 编译固件

先用代理拉取代码，切换到当前固件版本，为设备编译

- [Download the latest source code from GitHub · RMerl/asuswrt-merlin.ng Wiki](https://github.com/RMerl/asuswrt-merlin.ng/wiki/Download-the-latest-source-code-from-GitHub)
- [Compile Firmware from source · RMerl/asuswrt-merlin.ng Wiki](https://github.com/RMerl/asuswrt-merlin.ng/wiki/Compile-Firmware-from-source)

```shell
sudo mount -o size=16G -t tmpfs none /mnt/tmpfs
cd /mnt/tmpfs

git clone https://gh-proxy.com/https://github.com/RMerl/asuswrt-merlin.ng.git
cd asuswrt-merlin.ng
git checkout -b 3004.388.9_2

cd asuswrt-merlin.ng/release/src-rt-5.02L.07p2axhnd
make rt-ax86u
```

```
Done! Image 962118GW has been built in /build/release/src-rt-5.02L.07p2axhnd/targets/962118GW.
```

## 发现 MCPD

源码调试以后确认是有进程已经占用了 IGMP 的位置，尝试 `netstat -anp | grep 'raw'` 发现叫 `mcpd` 的进程很可疑，查了一下它的配置文件，确实是负责 IGMP 的。

- [asuswrt-merlin compatibility · troglobit/smcroute · Discussion #201](https://github.com/troglobit/smcroute/discussions/201) 这里是同样的端口被占用的报错，原因是不论路由器界面的 `LAN > IPTV > 启动组播路由` 开没开，MCPD 进程都会启动，占用这个。
- [IGMP Snooping (multicast forwarding) on AX routers? | SNBForums](https://www.snbforums.com/threads/igmp-snooping-multicast-forwarding-on-ax-routers.58245/) 这里提到可以自定义 postconf。虽然 [Custom config files · RMerl/asuswrt-merlin.ng Wiki](https://github.com/RMerl/asuswrt-merlin.ng/wiki/Custom-config-files) 上列了支持 igmpproxy.postconf 但没写支持 mcpd.postconf，但 [代码上](https://github.com/RMerl/asuswrt-merlin.ng/commit/20dbf936f14c179d3063237b21cb7fb692f45102) 是可以的

然而 mcpd 在代码库里是以 [预编译二进制](https://github.com/RMerl/asuswrt-merlin.ng/tree/ed4904e957f9b9701eef584e498ab17dcaec99e3/release/src-rt-5.02L.07p2axhnd/router-sysdep.rt-ax86u/mcpd) 的形式分发的 😦，也没个文档。
还好万能的 GitHub 搜索关键字还是有结果的，在 RT-AC1200G+ 的固件里找到了 [MCPD源代码](https://github.com/clockzhong/ASUSWRT_RT-AC1200GPlus/tree/78d1b417a92ce8305e841b9751d4273ad3f4f0c1/release/src/router/mcpd)

拉一遍源码 500MB 实在太慢了，有请 *稀疏检出*
- [git - Is it possible to do a sparse checkout without checking out the whole repository first? - Stack Overflow](<https://stackoverflow.com/questions/4114887/is-it-possible-to-do-a-sparse-checkout-without-checking-out-the-whole-repository/63786181#63786181>

```shell
git clone https://gh-proxy.com/https://github.com/clockzhong/ASUSWRT_RT-AC1200GPlus.git --filter=tree:0 --no-checkout --depth=1
cd ASUSWRT_RT-AC1200GPlus/
git sparse-checkout add release/src/router/mcpd/
git sparse-checkout add release/src/router/mcpctl/
git checkout
```

别高兴的太早，想要编译 mcpctl 还少了头文件 `mcpctl.h`，还好也能在网上找到 [rikka0w0/Arris-CM8200B-Reverse-Engineering](https://github.com/rikka0w0/Arris-CM8200B-Reverse-Engineering/blob/f841267f8ae772912000c3af79b77b8c45735da6/docs/asuswrt-merlin.ng/release/src-rt-5.02hnd/userspace/private/include/mcpctl.h#L49)。
