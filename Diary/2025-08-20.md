## 在 VSCode 中禁用 JSON Schema 验证

[Don't use JSON schema when editing YAML file in Visual Studio Code - Stack Overflow](https://stackoverflow.com/questions/71765669/dont-use-json-schema-when-editing-yaml-file-in-visual-studio-code)

文件头上加个注释就行

```yaml
# yaml-language-server: $schema=https://json.schemastore.org/yamllint.json
```
