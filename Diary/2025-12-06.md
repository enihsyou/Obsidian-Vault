## Prettier 内联忽略文件

不想在项目中再多一个 .prettierignore 文件，并且还希望 ignore pattern 能和 Sharable Configurations 一起打包共享。[Ignore commonly generated folders · Issue #4547 · prettier/prettier](https://github.com/prettier/prettier/issues/4547#issuecomment-1606712871) 给出了个好办法，使用 `requirePragma` 来在没主动指定标记的文件中关闭格式化

```javascript title=prettier.config.mjs
/**
 * @see https://prettier.io/docs/configuration
 * @type {import("prettier").Config}
 */
const config = {
  // 文件特殊规则
  overrides: [
    {
      // requirePragma 用来禁用格式化
      // https://github.com/prettier/prettier/issues/4547#issuecomment-1606712871
      files: ["pnpm-lock.yaml"],
      options: { requirePragma: true },
    },
  ],
};

// noinspection JSUnusedGlobalSymbols
export default config;
```
