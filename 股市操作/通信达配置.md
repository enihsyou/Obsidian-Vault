## 指标公式

### 分时买卖

编写过程：[[2026-02-12#通达信在分时图中取昨日最高价]]

根据昨日收盘价决定在支撑压力位决定操作，思路来自 [通达信分时t0准确买卖指标公式-股民学校-金投网](https://stock.cngold.org/school/c2974474.html)，加以修改，使用动态阻力值。大部分代码在计算昨日收盘价

```zig
最后一日:=DATE==CONST(DATE);
最先一日:=DATE==CONST(REF(DATE,TOTALBARSCOUNT-1));

日首根线:=DATE<>REF(DATE,1);
当日线数:=BARSLAST(日首根线)+1;

今开盘价:=IF(最后一日, DYNAINFO(4), 价格引用.当前开盘价#DAY);
昨收盘价:=IF(最后一日, DYNAINFO(3), 价格引用.上一收盘价#DAY);
近日最高:=价格引用.前三日最高#DAY;
近日最低:=价格引用.前三日最低#DAY;
近日振幅:=近日最高 - 近日最低;
近日阻力:=近日最低 + 近日振幅 * 0.618;
近日支撑:=近日最高 - 近日振幅 * 0.618;

H1:=MAX6(昨收盘价, 今开盘价, HHV(H, MIN(短期周期*2, 当日线数)), 近日阻力, L, L);
L1:=MIN6(昨收盘价, 今开盘价, LLV(L, MIN(短期周期*3, 当日线数)), 近日支撑, H, H);
P1:=(H1-L1)*1 /16;

均线:=IF(日首根线, 今开盘价, SUM(V*C,当日线数)/SUM(V,当日线数));
阻力:H1-P1,COLORGREEN,LINETHICK2;
支撑:L1+P1,COLORRED,LINETHICK3;

短期:EMA(CLOSE,MIN(短期周期, 当日线数)),NODRAW;
强弱:均线,COLORYELLOW;
现价:CLOSE,COLORWHITE,LINETHICK2;

STICKLINE(短期>强弱,短期,强弱,0,0),COLORRED;  {强势程度}
STICKLINE(短期<强弱,短期,强弱,0,0),COLORCYAN; {弱势程度}

弱转强:=CROSS(短期,强弱);
强转弱:=CROSS(强弱,短期);
CROSS(短期,强弱),PLAYSOUND5;
DRAWICON(弱转强,现价,42);
DRAWICON(强转弱,现价,43);

可能反弹:=CROSS(支撑,现价);
可能回调:=CROSS(现价,阻力);

STICKLINE(可能反弹,支撑,阻力,1,0),COLORYELLOW;
STICKLINE(可能回调,支撑,阻力,1,0),COLORCYAN;

日内买点:=LONGCROSS(支撑,现价,2);
日内卖点:=LONGCROSS(现价,阻力,2);
LONGCROSS(支撑,现价,2),PLAYSOUND4;
LONGCROSS(现价,阻力,2),PLAYSOUND3;
DRAWICON(日内买点,支撑,34);
DRAWICON(日内卖点,现价,35);
```

```zig title=价格引用
上一最高价:REF(H, 1);
上一最低价:REF(L, 1);
上一开盘价:REF(O, 1);
上一收盘价:REF(C, 1);
上一日期:REF(DATE,1),NODRAW;

当前最高价:H;
当前最低价:L;
当前开盘价:O;
当前收盘价:C;
当前日期:DATE,NODRAW;

前四日最高:HHVLLV(H, 0, 4, 1);
前四日最低:HHVLLV(L, 1, 4, 1);
前三日最高:HHVLLV(H, 0, 3, 1);
前三日最低:HHVLLV(L, 1, 3, 1);
前二日最高:HHVLLV(H, 0, 2, 1);
前二日最低:HHVLLV(L, 1, 2, 1);
```

- RED 采用 LINETHICK3，为了在显示上给肉眼与 GREEN 等宽的错觉
- 5MIN 线的精度比 1MIN 线要高，分时图的 1MIN 线取不出高低开收价，都是同一个值

### 主图买卖

同上，展示昨日收盘价决定的支撑压力位，适合主图叠加。我一般用在 5 分钟线上
与分时不同的是，使用当日最高最低价画线，所以指标决策盘中会随市场变化

```zig
今开盘价:=DYNAINFO(4);
昨收盘价:=DYNAINFO(3);
今最高价:=DYNAINFO(5);
今最低价:=DYNAINFO(6);

H1:=MAX(昨收盘价, 今最高价);
L1:=MIN(昨收盘价, 今最低价);
P1:=(H1-L1)*1 /16;

阻力:H1-P1,COLORGREEN,LINETHICK2;
支撑:L1+P1,COLORRED,LINETHICK3;

EXP12:EXPMA.EXP1(12, 60),LINETHICK3,COLORYELLOW;
EXP60:EXPMA.EXP2(12, 60),LINETHICK3,COLORLIMAGENTA;
```
