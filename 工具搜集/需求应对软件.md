## 开发工具版本管理

通用的多语言的版本管理，而非针对单一语言，所以 rbenv、uv 不在此列。
主要需求是
1. 能改下载源，走镜像加速下载
2. 不乱改全局 PATH，激活时最好集中到一处 PATH 条目
3. 全平台支持
目前看了这么写选择，最后还是 vfox
- [asdf](https://asdf-vm.com/)
- [vfox | The Multiple SDK Version Manager](https://vfox.dev/) like asdf but with Windows support，shim 性能高
- [X-CMD | 模块化构建的命令行工具集, 提供 1000+ 轻量且高效的命令, 秒级启动](https://cn.x-cmd.com/) based on Git-Bash on Windows, but with much more features
- [Home | mise-en-place](https://mise.jdx.dev/) Shim 在 Windows 上性能不是很好

### 终端文件管理器

[文件管理器全景指南 | x-cmd install](https://cn.x-cmd.com/install/25-ls)

需求：
- 简单地树状列出文件
- 能预览文本文件
- 跨平台，多架构，无依赖

当前：
- lf 主力，操作简单，无需配置
- yazi 还未习惯输入它的名字

备选：
- [broot](https://dystroy.org/broot)
	- 更适合用作文件一览，搜索倒不如 fzf 了
- [ranger](https://github.com/ranger/ranger)
	- Python
- [yazi](https://yazi-rs.github.io/) 胜出
	- 多栏文本自动折行
	- filter 和 find 能保持状态
	- 和 fd rg fzf 集成
- [lf](https://github.com/gokcehan/lf)
	- 文件预览无颜色
	- 应用内没有帮助页面，在 [这里](https://github.com/gokcehan/lf/blob/master/doc.md#quick-reference)
- <https://github.com/jarun/nnn>
	- No Windows Native Support, but Cygwin

yazi 必知技巧

- `s` 使用 fd 搜索文件
- `S` 使用 ripgrep 搜索内容
- `J/K` 滚动预览框

## 二进制文件

### 内容展示

### 内容分析

- [binsider | x-cmd install](https://cn.x-cmd.com/install/binsider) Binsider 可以执行静态和动态分析、检查字符串、检查链接库以及执行十六进制转储，所有这些都在用户友好的终端用户界面中完成
  支持 Windows 的版本还未发布，需要 `cargo install binsider --no-default-features --git https://github.com/orhun/binsider` 安装，只能分析 ELF 文件，非 PE
- [ReFirmLabs/binwalk: Firmware Analysis Tool](https://github.com/ReFirmLabs/binwalk)

### 文件对比
