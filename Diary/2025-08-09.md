## HTTPie 启动耗时太慢
```powershell
$ Measure-Command { httpie --version } | % TotalSeconds
0.5114763  
$ Measure-Command { xh --version } | % TotalSeconds
0.0157881
$ Measure-Command { curl --version } | % TotalSeconds
0.0131859
```
HTTPie/cli 最近的版本还是去年的 3.2.4 ，并且 13 年前的对 IPv6 only 支持的需求[Add -4 and -6 switches to force IP protocol version · Issue #94 · httpie/cli](https://github.com/httpie/cli/issues/94)到现在都没加上，换成 [ducaale/xh: Friendly and fast tool for sending HTTP requests](https://github.com/ducaale/xh) Rust 版了。

解决方式一：本地流量不 mangle
```shell
iptables -t mangle -I PREROUTING 1 -s 192.168.9.0/24 -d 192.168.2.0/24 -j RETURN
iptables -t mangle -I PREROUTING 1 -s 192.168.2.0/24 -d 192.168.9.0/24 -j RETURN
```
解决方式二：把 DROP 指令删掉
```shell
iptables -t mangle -D merlinclash_divert -m conntrack --ctstate INVALID -j DROP
```
