## JSX 中异步加载字体样式表

之前在 [[2025-08-22#博客网站性能优化]] 上调整过 webfont 加载相关逻辑，取得不错的效果。现在打算在 [[Publish Obsidian Vault]] 网页上用更加 2025 年现代的方式再实践一遍。
- [Speed Up Google Fonts – CSS Wizardry](https://csswizardry.com/2020/05/the-fastest-google-fonts/)
- [How to Load Fonts in a Way That Fights FOUT and Makes Lighthouse Happy | CSS-Tricks](https://css-tricks.com/how-to-load-fonts-in-a-way-that-fights-fout-and-makes-lighthouse-happy/)
- [Font style matcher](https://meowni.ca/font-style-matcher/)

使用 preload 改造为异步加载，但是在 JSX 中做有些麻烦，不应该用 React 的 `onLoad`，而是 HTML 原生的 `onload`，得动态注入

```jsx
/** 往 JSX 中添加 onload 属性 */
function preloadStylesheetOnloadFn() {
  return { 'onload': 'this.onload=null;this.rel="stylesheet"' };
}

function misansFontStylesheet(): JSX.Element {
  return (
    <>
      <link rel="preload" as="style" crossorigin="anonymous"
        {...preloadStylesheetOnloadFn()}
        href="https://cdn.jsdelivr.net/npm/misans-vf@1.0.0/lib/MiSans.min.css" />
    </>
  )
}
```
