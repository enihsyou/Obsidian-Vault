## 调整水冷水泵转速，减少电脑噪音

#AIGC

今天在比较安静的环境下用电脑，发现机箱风扇和 CPU 水冷水泵的声音非常抓耳。

先在 BIOS 里调整风扇，让它在温度低的时候自动停止，再把 CPU Power Mode 切换到节能模式，盖上机箱静音盖，风扇的声音就缓解了。之前 [[Diary/2026-10-13#调节 Windows 最大处理器状态]] 记录过 Windows 电源管理的设置，节能模式把最大处理器状态限制在 99%，避免自动超频。

但水泵还在响。我的水冷是比较早的海盗船 H115i（CW-9060027-WW），这次测下来水泵转速大约在 2000～3000 RPM 之间。iCUE 里只能选 Balance 和 Performance 两档，大致相当于最低和最高转速，想调到中间也没办法。

后来找到了 [liquidctl](https://github.com/liquidctl/liquidctl)，在 Windows 上需要用 [Zadig](https://zadig.akeo.ie/) 给这个设备安装 WinUSB 驱动，替换掉 iCUE 使用的设备驱动，然后就能在终端中调节水泵速度。它接受 50%～100% 的设置值，虽然实际上是映射到离散档位，但比 iCUE 的两档细得多。

```console
$ liquidctl list --verbose
Device #0: Corsair Hydro H115i
├── Vendor ID: 0x1b1c
├── Product ID: 0x0c0a
├── Release number: 0x0100
├── Serial number: 7289_2.0
├── Bus: usb2
├── Address: 4
├── Port: 17
└── Driver: Hydro690Lc
```

试了一下，50% 时大概是 2000 RPM，低频声音非常大；调到 100%，转速约 3000 RPM，高频声音又很难受。最后调到 62%，水泵速度在 2250～2280 RPM 之间，声音听着比较舒服。

```powershell
liquidctl set pump speed 62
```

```console
$ liquidctl status --verbose
Corsair Hydro H115i
├── Liquid temperature       40.0  °C
├── Fan speed                   0  rpm
├── Pump speed               2280  rpm
└── Firmware version      2.8.0.0
```

代价是这个设备会被看作可插拔设备，显示在右下角的设备管理页面，并且每次开机需要设置一下这个转速。

## 禁用 Codex 用不到的自带插件和 Skill

Codex 有很多我用不到的功能，比如 Pages、Sites、Pets，但是又不能在界面上直接关闭，就只能从 `~/.codex/config.toml` 配置文件里关掉。

那 Codex 总是留下很多障碍
- 默认安装一堆什么 defense_factory，hotline 插件
- 强制开启 `remote_plugin`，禁用了也没用 [Codex issue #28443](https://github.com/openai/codex/issues/28443)
- 还有无法关闭的看不见摸不着的 codex_apps MCP

禁用插件 Skill 时，在 `[[skills.config]]` 中使用带插件前缀的完整名称，并设置 `enabled = false`：

```toml
[features]
remote_plugin = false
apps = false          # 关闭 codex_apps MCP
# codex_apps MCP 提供了
# - openai-templates@openai-curated-remote
# - pages@openai-curated-remote
# - sites@openai-curated-remote
# - work-pets@openai-curated-remote
# 目前无法通过任何其他方式禁用 https://github.com/openai/codex/issues/28443

[plugins."browser@openai-bundled"]
enabled = true
[plugins."unified-computer-use@openai-bundled"]
enabled = true
[plugins."computer-use@openai-bundled"]
enabled = true

[plugins."openai-templates@openai-curated-remote"]
enabled = false
[plugins."pages@openai-curated-remote"]
enabled = false
[plugins."sites@openai-curated-remote"]
enabled = false
[plugins."work-pets@openai-curated-remote"]
enabled = false

[apps.connector_openai_hotline]
enabled = false
[apps.connector_openai_defense_factory]
enabled = false
[apps.connector_openai_codex_document_control]
enabled = false
[apps.connector_openai_pages]
enabled = false
[apps.connector_openai_chatgpt_pets]
enabled = false
[apps.connector_openai_safety_settings]
enabled = false
[apps.connector_openai_plugin_management]
enabled = false
[apps.connector_openai_default_templates]
enabled = false

# Disable selected plugin skills.
[[skills.config]]
name = "work-pets:create-pet"
enabled = false
[[skills.config]]
name = "work-pets:pets"
enabled = false
[[skills.config]]
name = "work-pets:update-pet"
enabled = false
[[skills.config]]
name = "pages:maintain-space"
enabled = false
[[skills.config]]
name = "pages:manage-schedules"
enabled = false
[[skills.config]]
name = "pages:organize-space"
enabled = false
[[skills.config]]
name = "pages:write-page"
enabled = false
[[skills.config]]
name = "sites:sites"
enabled = false
[[skills.config]]
name = "sites:sites-remix"
enabled = false
```

禁用 Skill 需要写完整的名字，包含前缀的。如果使用本地绝对路径，会在切换系统或者版本更新的时候失效。

还需要手动执行命令卸载

```shell
codex plugin remove documents@openai-primary-runtime
codex plugin remove pdf@openai-primary-runtime
codex plugin remove spreadsheets@openai-primary-runtime
codex plugin remove presentations@openai-primary-runtime
codex plugin remove template-creator@openai-primary-runtime
```

## 微信强制用常用小程序列表替代我的小程序列表

微信 iOS 手机端更新 `8.0.80` 后，主界面下拉原先的 `我的小程序` 列表被 `常用小程序` 替代了。

这就是为了显示广告，因为常用小程序和最近使用小程序基重叠度非常高。而我的小程序的作用基本就是收藏。

需要去 `发现页` > `小程序` > 右上角点击头像进入个人中心>关闭 `我的常用小程序`。
