## Windows 开机闪现个控制台创建

#未解之谜
一直存在这个现象，开机/重启登录后，会弹出一个没有内容的控制台窗口（经由 Windows Terminal 显示）。今天观察到了标题栏上的内容，好像是来自 `C:\msys2\usr\bin`，还有 `git` 什么关键字，但这两个组合不起来… 下次看到再说

`2026-05-24` 观察到了是 `"C:\Program Files\Git\usr\bin\gpgconf.exe" --launch gpg-agent` 来自 gpg-agent demon 定时任务，在用户登录时启动。

## 腾讯云服务器因动态 IP 变更被防火墙拦截

#云服务

今天注意到 [2025-08-27 > 38 元抢到腾讯云轻量应用服务器](Diary/2025-08-27#38%20元抢到腾讯云轻量应用服务器) 腾讯云服务器宝塔面板入口无法访问了。

检查发现是之前设置的防火墙规则为宝塔访问端口限定了 IP 范围，这就和之前在 [2025-11-07 > Limit Client IP Ranges for Cloudflare API Token](Diary/2025-11-07#Limit%20Client%20IP%20Ranges%20for%20Cloudflare%20API%20Token) 上遇到的一样。更新记录就好。
