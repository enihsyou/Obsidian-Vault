## Zed 中 Gemini CLI 一直处于 Loading 状态

表现是 New Gemini CLI 时，一直 Loading...，明明在终端可以正常使用。
尝试过降级 node=20；编译安装 node-gyp；删除 Zed external_agents 缓存目录；重新安装 gemini-cli 都不行。

原来是新发布的 gemini-cli v0.18 有 bug，`bun install -g @google/gemini-cli@v0.17` 降低到 v0.17 就好了
- [Gemini CLI stuck in "Loading..." · Issue #38750 · zed-industries/zed](https://github.com/zed-industries/zed/issues/38750#issuecomment-3580678817)

刚发的版本，也算是被我遇上了。
