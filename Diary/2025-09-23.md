## Suppress Trailing Comma Warning for JSONC file in VSCode

VSCode 在 JSONC 文件中会对 `尾随逗号 jsonc(519)` 产生警告，很明显是非期望的，否则失去了这个语言的特性。

VSCode 侧非常不愿意修改默认行为或者开放配置，觉得在 Schema 没有明确指定的情况下就该产生警告。

好吧那就自定义个 Schema ，[Tolerate trailing commas in jsonc format · 议题 #102061 · microsoft/vscode](https://github.com/microsoft/vscode/issues/102061#issuecomment-657080963)

```jsonc title="settings.json"
"json.schemas": [
  {
    // https://github.com/microsoft/vscode/issues/102061#issuecomment-657080963
    "fileMatch": [ "*.jsonc" ],
    "schema": {
      "allowTrailingCommas": true
    }
  }
],
```

## 本地编译使用 goreleaser 的项目

```shell
goreleaser build --snapshot --single-target --clean
```

有的软件通过在 hook 中绑定 Windows 可执行文件的图标，注意就不要 `--skip=post-hooks --skip=before` 了

但如果遇到还未适配 v2 的，需要下载 v1.26 的 goreleaser

```shell
goreleaser_v1 check
goreleaser_v1 build --snapshot --single-target --clean
```

## golang 启动会寻找 gcc

处理 [[PowerShell Profile#version-fox shim 会叠加一层耗时]] 时发现 golang 会扫描 PATH 寻找 gcc，花费了上百毫秒，光输出个 version 就等待好久。

代码对应这里 [go/src/cmd/go/internal/cfg/cfg.go at 9b2d39b75bcc8ced3eaab1c841d7d62e27867931 · golang/go](https://github.com/golang/go/blob/9b2d39b75bcc8ced3eaab1c841d7d62e27867931/src/cmd/go/internal/cfg/cfg.go#L173)，而它的条件 `ctxt.CgoEnabled` 又是在 [go/src/go/build/build.go at 9b2d39b75bcc8ced3eaab1c841d7d62e27867931 · golang/go](https://github.com/golang/go/blob/9b2d39b75bcc8ced3eaab1c841d7d62e27867931/src/go/build/build.go#L371) 设置上的

日常编译不需要 cgo，等有必要了用 docker 编译才是正道。

配置一下全局禁用 cgo，加速启动

```
$env:CGO_ENABLED="0"
```

然而还有一个查找 `gccgo` 的流程，[go/src/cmd/go/internal/work/gccgo.go at 9b2d39b75bcc8ced3eaab1c841d7d62e27867931 · golang/go](https://github.com/golang/go/blob/9b2d39b75bcc8ced3eaab1c841d7d62e27867931/src/cmd/go/internal/work/gccgo.go#L41) 这个就没办法绕过了，除非自己编译 go
