## 更新 BIOS 版本至 F12 后启动 Windows 提示 0xC0430001 错误

我的主板是 [GIGABYTE X870E AORUS ELITE WIFI7 (rev. 1.0)](https://www.gigabyte.cn/Motherboard/X870-AORUS-ELITE-WIFI7-ICE-rev-10-11/support)， Windows 个性化的动态光效中就能控制我主板上的灯光。

我的内存条是金百达的 DDR5 32GB x 2，想要控制内存条的灯光，就需要单独启动 [Kingbank RGB Control Software](https://www.kingbank.com/ControlHub.html)。

CPU 散热器就是海盗船 H115i，想要控制它的灯光，还得要单独安装一个 CORSAIR iCUE。

各个厂商自己玩自己的，今天看到 [Glance](https://github.com/lulu-loopp/glance) v.3.0 添加了 OpenRGB 控制设备灯光的功能，本以为他能统一我的所有控制面。实际使用起来，它虽然能识别，但并不能控制我设备上的任何灯光。

主板之前安装的是 2025-01-04 的 `F3j` 版本（现在居然下架了），就想要通过更新到 `F12` 版本看看有没有新功能。没想到安装完之后，不仅重置了我的 BIOS 超频设置，而且直接无法启动 Windows。启动就提示你的电脑需要恢复，0xC0430001 错误。

几经周转，最终确认是 BIOS 上的 Secure Boot 在 F9 版本中被默认启用了。虽然我记得之前的版本我是开启状态，但是在 BIOS 中把 Secure Boot 关闭之后确实能启动系统了。

启动之后，Windows Hello PIN 登录直接废了，需要用密码登录。在 Windows 账户设置中，PIN 那一栏直接显示该选项不可用，提示“抱歉，此 PIN 不能用于你组织的资源”。看上去需要一个组织账户，但我是个人账户。

在 Windows 系统登录界面点重置 PIN 倒是能把这个 PIN 重置并且设置上。到此也算是勉强完成了吧，结合以后肯定会更新的 [[Diary/2026-09-18#KB5129195 更新导致 Primo Ramdisk 驱动签名失效]]，这个 Secure Boot 还真的得关闭。

## AMD 9700X 超频配置

刚才更新 BIOS，把之前的配置都清空了。倒也还能接受，我本来就喜欢定期大赦天下，从默认值开始感受新版本有什么变化。不过我居然一直没记录过超频参数，这次只能从头开始试，顺便把过程和最后留下的配置记下来。

内存用了默认的 EXPO 配置，6400 MT/s，时序 32-39-39-89。`UCLK = MEMCLK` 不稳定，只能用 `UCLK = MEMCLK/2`。

CPU 一开始设的是 PPT 96 W、TDC 84 A、EDC 160 A，CPU Boost Override +100 MHz，PBO Scalar 3x，Curve Optimizer 全核心 -10，Tji 保持默认 95℃。这组配置下核心最高温度到了 80℃，PPT 已经打满，还有继续调整的空间。

之后用 Ryzen Master 做 Curve Optimizer 自动优化，给出的建议居然是全核心 -53，CPU-Z 跑分也提升了不少。改成每核心优化，建议值则是 -60，多线程分数又高了一点，不过这两次都受到了 PPT 限制。我又把 PPT 放到 105 W，Tji 限到 92℃，多线程分数还能继续往上走。几次结果放在一起比较：

| 配置                     | CPU-Z 单线程 / 多线程 | 最高温度  |
| ---------------------- | --------------- | ----- |
| PPT 96 W，全核心 -10       | 787.6 / 7753.4  | 80℃   |
| PPT 96 W，全核心 -53       | 821.8 / 8494.6  | 78.5℃ |
| PPT 96 W，每核心优化，建议值 -60 | 815.8 / 8589.8  | 78.4℃ |
| PPT 105 W，Tji 92℃      | 820.6 / 8856.1  | 92.3℃ |
| 最终配置                   | 845.8 / 9010.3  | 95.5℃ |

最后留下的是 PPT 125 W、TDC 96 A、EDC 160 A，Curve Optimizer 全核心 -50，Tji 恢复默认。相比老古董 Intel i7-7700K 的单线程 492 分、多线程 2648 分，我觉得足够了。
