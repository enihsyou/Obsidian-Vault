## 允许外部通过容器名解析至 Docker

#Docker
之前做好了 [[2025-11-16#给 Docker 配置完整的 IPv6 macvlan 网络环境]]，局域网内可以直接通过路由器访问到容器网段，下一步便是让容器外也能直接 DNS 解析容器名，当然仅对加入到特定网络的容器生效。

相同的想法早有人实现了，这里照搬验证
- [Exposing Docker's internal DNS with CoreDNS :: TheOrangeOne](https://theorangeone.net/posts/expose-docker-internal-dns/)
别忘了之前必不可少的铺路过程
- [[2025-11-20#发送文件到 Docker Remote]]

首先创建网络，注意这里创建的网络名可以当做后缀来访问，比如这个网络可以解析 `coredns.docker` 这个域名到名为 coredns 的容器。

```shell title="On Docker Engine Host"
docker network create -d macvlan --ipv6 \
  -o parent=ens19 \
  --subnet=192.168.2.0/24 --gateway=192.168.2.1 \
  --ip-range=192.168.2.128/25 docker
```

然后创建 CoreDNS 配置文件，这里的 127.0.0.11 是 Docker Engine 的内置 DNS 服务器地址。在容器中查看 /etc/resolve.conf 能发现这一点 [從 KIND 環境中學到的 DNS 小趣聞 | hwchiu learning note](https://www.hwchiu.com/docs/2023/kind-network)

```nginx title="Corefile"
. {
    errors
    cancel

    # forward to docker internal DNS server
    forward . 127.0.0.11
}
```
