## Edge 浏览器从 HTTP 站点下载文件提示不安全

从 HTTP 站点下载文件时，Edge 会提示无法安全下载该文件。没错我已知风险了，即便点击保留，也不让保留。

好在下载实际还在后台执行，文件小的话，可以去磁盘中找到对应的 `.crdownload` 文件，把这段后缀名去掉也是能得到原文件。

因为在应用设置页面根本没有个完整的开关，不嫌烦的话，可以去 `隐私、搜索和服务 > 站点权限 > 所有权限 > 不安全的内容` 手动添加 URL。

更直接的是运行 `gpedit.msc`，禁用 `用户配置 > 管理模板 > Microsoft Edge > 下载 > 启用不安全的下载警告`。

## 移除 Windows 11 25H2 开始菜单下部应用窗格

借张图来自 [Windows11 家庭中文版 25H2 26200.7922 开始菜单怎么移除下面的文件夹？ - Microsoft Q&A](https://learn.microsoft.com/zh-cn/answers/questions/5791866/windows11-25h2-26200-7922) 的图 ![a1876fef-96a7-43fb-a966-b9d062626891 (822×856)](https://learn-attachment.microsoft.com/api/attachments/a1876fef-96a7-43fb-a966-b9d062626891?platform=QnA)

在这里有答案
- [Seriously, how do I hide this thing from my Start Menu? It's horrible. : r/Windows11](https://www.reddit.com/r/Windows11/comments/1qbnfwj/seriously_how_do_i_hide_this_thing_from_my_start/)
- [windows - Remove "All Apps" icon from Start Menu - Super User](https://superuser.com/questions/1560574/remove-all-apps-icon-from-start-menu)

记录下简体中文系统的操作路径
改注册表就这样：

```reg
Windows Registry Editor Version 5.00

[HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer]
"NoStartMenuMorePrograms"=dword:00000003
```

```shell frame=none wrap=true
reg add "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer" /v NoStartMenuMorePrograms /t REG_DWORD /d 3
```

改组策略就这样：
导航到 `用户配置 > 管理模板 > 开始菜单和任务栏 > 从开始菜单中删除所有程序列表`，状态修改为已启用，并且选项改为 `折叠`，即对应上面注册表的变更。不过按说明介绍，此选项应该会保留一个显示所有应用的按钮在右上角，可我没找到。所以等效另外两个 `折叠并禁用设置` 和 `删除并禁用设置`，分别对应 `NoStartMenuMorePrograms` 设置为 `2` 和 `1`

还可以进一步在 `个性化 > 开始` 或者组策略中把推荐项目和常用项目关掉，自行管理固定项目。
但目前关掉这些以后，开始菜单高度不会缩小，留下一大片空白。啊，又回到了 Windows 8 手动管理磁贴的时代了，体验还可接受，不就等同于手机桌面嘛。
