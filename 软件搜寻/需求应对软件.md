### 终端文件管理器

[文件管理器全景指南 | x-cmd install](https://cn.x-cmd.com/install/25-ls)

需求：
- 简单地树状列出文件
- 能预览文本文件
- 跨平台，多架构，无依赖

当前：
- yazi

备选：
- [broot](https://dystroy.org/broot)
	- 更适合用作文件一览，搜索倒不如 fzf 了
- [ranger](https://github.com/ranger/ranger)
	- Python
- [yazi](https://yazi-rs.github.io/) 胜出
	- 多栏文本自动折行
	- filter 和 find 能保持状态
	- 和 fd rg fzf 集成
- [~~lf~~](https://github.com/gokcehan/lf)
	- 文件预览无颜色
	- 应用内没有帮助页面
- <https://github.com/jarun/nnn>
	- No Windows Native Support, but Cygwin

yazi 必知技巧

- `s` 使用 fd 搜索文件
- `S` 使用 ripgrep 搜索内容
- `J/K` 滚动预览框

## 二进制文件

### 内容展示

- [hexyl | x-cmd install | 安装方式](https://cn.x-cmd.com/install/hexyl) sharkdp 老牌工具

### 内容分析

- [binsider | x-cmd install](https://cn.x-cmd.com/install/binsider) Binsider 可以执行静态和动态分析、检查字符串、检查链接库以及执行十六进制转储，所有这些都在用户友好的终端用户界面中完成
  支持 Windows 的版本还未发布，需要 `cargo install binsider --no-default-features --git https://github.com/orhun/binsider` 安装，只能分析 ELF 文件，非 PE
- [ReFirmLabs/binwalk: Firmware Analysis Tool](https://github.com/ReFirmLabs/binwalk)

### 文件对比

- [sharkdp/binocle: a graphical tool to visualize binary data](https://github.com/sharkdp/binocle) 图形化方式看二进制
- [Diffing | ImHex](https://docs.werwolv.net/imhex/views/diffing)
- `delta <(xxd a.bin) <(xxd b.bin)`
- `binwalk -W file1.bin file2.bin`
